# ValoBalance

Dashboard for a 10-hour forecast of the Finnish imbalance price in 15-minute steps: P10, P50 and P90, spike risk above and below spot, regulation direction, drivers and alerts. This static version shows the precomputed validation and test forecasts.

Contains data from Fingrid Open Data and the ENTSO-E Transparency Platform (CC BY 4.0).
